# ML Talks Notes

Notes, Q&A summaries and vocabulary from watching conference talks on [ML Talks](https://mkj69.github.io/ml-talks/).

This repo is written by the ML Talks notes agent. Each time a talk's Q&A is organized, the agent commits here, and the site reads the notes back from this repo.

- `talks/<conf>-<year>-<id>.md`: one note per talk
- `index.md` / `index.json`: every noted talk
- `vocab.md` / `vocab.json`: every term asked about, merged across talks
